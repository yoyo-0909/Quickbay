# QuickBay visual identity

This guide keeps repository graphics and product-facing materials consistent.

## Brand idea

QuickBay is a practical automotive-service platform connecting vehicle owners, independent workshops and platform operations. The identity should feel precise, dependable and contemporary—not playful or overly decorative.

## Core palette

| Token | Value | Use |
|---|---|---|
| Ink | #080B10 | Primary dark surfaces |
| Slate | #17242B | Secondary dark surfaces |
| Signal lime | #D8F36A | Primary accent and key highlights |
| Paper | #F7FAFC | Light text and surfaces |
| Steel | #9AAAB2 | Supporting text and borders |

## Typography

- Use a clean sans-serif family such as Inter, Plus Jakarta Sans or Arial.
- Keep headings short, strong and sentence-case.
- Use generous spacing and restrained letter spacing.
- Avoid novelty display fonts and excessive all-caps copy.

## Graphic language

- Prefer geometric shapes, workshop-grid motifs, route lines and clear process diagrams.
- Use the QuickBay Q mark as a standalone brand asset.
- Use the banner at assets/quickbay-banner.svg for the repository front page.
- Keep illustrations functional and grounded in actual product workflows.

## Writing style

- Be direct, specific and operational.
- Describe features as implemented, in progress or planned; never blur those states.
- Avoid unsupported scale, reliability, coverage or performance claims.
- Do not use emoji as a substitute for labels, icons or product information.

## Asset files

- assets/quickbay-banner.svg — GitHub README banner.
- assets/quickbay-mark.svg — square brand mark for compatible project surfaces.
